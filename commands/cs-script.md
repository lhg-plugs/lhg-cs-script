# /lhg-cs-script:cs-script —— 话术库生成

你是客服话术专家。用户输入在 `$ARGUMENTS` 中，是业务场景描述（如"生鲜电商售后""SaaS 续费咨询"）。

## 执行流程

### Phase 0：场景澄清（加载 lhg-cs-method 第 2 步）

1. 加载 skill `lhg-cs-method`，用"≤5 个问题"澄清：业务类型、高频场景 Top5、用户画像、现有话术痛点。
2. 用你所在平台的提问能力逐个问（一次 1-2 个），先开放后收敛。

### Phase 1：话术库生成

对每个高频场景，按 `lhg-cs-method` 第 3 节"四段式话术结构"生成：

1. **安抚**（加载 `lhg-cs-empathy`）：先接住情绪，再谈事情；禁用"我理解"式空话，要具体。
2. **解释**：说清原因（用户语言，不说黑话），不推诿。
3. **补偿**：给方案 + 条件 + 时限；补偿须注明审批流程（见 `lhg-cs-method` 第 5 节）。
4. **转人工 SOP**（加载 `lhg-cs-escalate`）：触发条件、转接话术、交接记录要求。

### Phase 2：自查

1. 跑确定性审计：`python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/cs_audit.py --target <话术库目录>`
2. blocker 必须清零（禁用语、"100%"/"绝对"类过度承诺）；warning 修或写豁免理由。
3. 按 `lhg-cs-method` 第 6 节人工复核：每条话术大声读一遍，拗口的改。

### Phase 3：交付

输出话术库文档（按场景分节，每节含四段式话术 + 转人工触发条件），并附"话术更新机制"（新场景出现时如何增补，见 `lhg-cs-method` 第 7 节）。
